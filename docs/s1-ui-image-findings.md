# S1 UI 圖片核對記錄

## 來源與核對方式

使用者提供的寬幅介面圖片經原尺寸檢查與重疊切片核對，並比對近期上傳的 S1 風控設定原圖。

## 已確認範圍

- 「參數優化」區的「智能優化」、「手動進階」、「掃描佇列」、「歷史記錄」與「對比」均不是本次隱藏目標，必須保留。
- 掃描歷史卡片的策略名稱、交易對、時間框架、組合進度、日期、標準模式、進行中狀態，以及「檢視」與「刪除」操作均必須保留。
- 本次需從全部回測策略配置卡隱藏的精確區塊是「S1 單模式與風控政策」，包含 BACKTEST 標籤、S1「單倉獨占」卡片、已鎖定狀態、Gross 上限、Margin 上限、能力 TTL、反向訊號處理與 Preflight 說明。
- UI 隱藏不等於刪除底層能力。canonical S1 profile、預檢、Gross／Margin／TTL／反向訊號預設值、回測 payload 與執行安全邏輯均不得刪除或改寫。
- UI 隱藏後，回測仍須在背景以既有 S1 封印配置運作，不能將必要欄位改成 `undefined`，也不能讓快照或 runner 認證失效。
