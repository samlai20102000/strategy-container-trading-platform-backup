# KAMA 3K V6.1 高頻掃射極致版 — 策略分析

## 核心差異（V6.1 vs V3.5/V5.0）

| 維度 | V3.5 | V5.0 | V6.1（本次新建） |
|------|------|------|-----------------|
| 入場邏輯 | 3K 形態突破 | 3K 形態 + ADX 過濾 | **區域觸發**（KAMA_Slow ± Buffer×ATR） |
| 緩衝區 | 無 | 無 | **動態緩衝**（依市場制度 0.25/0.30/0.50×ATR） |
| 方向模式 | KAMA 方向鎖 | KAMA 方向鎖 | **三模式**（Trend/Hybrid/Both） |
| 入場模式 | 固定 | 固定 | **Breakout/Inside 可選** |
| ATR 過濾 | 無 | 有 | **最小 ATR 比率過濾** |
| 連續虧損 | 無 | 無 | **動態縮倉**（3筆70%/5筆50%） |
| 每日風控 | 無 | 無 | **每日交易次數+虧損上限** |
| 冷卻期 | 有（固定） | 有 | **可選（0=無冷卻，高頻模式）** |
| Bar-Lock | 強制 | 強制 | **可選（可解除，高頻模式）** |
| 連續開倉 | 不支持 | 不支持 | **支持（enable_continuous_entry）** |
| 止盈 | 固定%+移動 | ATR動態 | **ATR動態+最小%保底** |
| 馬丁參數 | 固定分層 | 制度自適應 | **制度自適應+階梯式step** |

## 六大核心機制
1. **區域觸發入場**：取代 3K 形態，價格在 KAMA_Slow ± Buffer 範圍即觸發
2. **動態緩衝區**：依 ADX 市場制度自動調整緩衝區寬度
3. **方向模式**：Trend/Hybrid/Both 三種可選
4. **突破確認模式**：Inside（區內開倉）/ Breakout（穿出邊界開倉）
5. **最小 ATR 過濾**：ATR < 0.7×ATR_MA(50) 時暫停開新倉
6. **連續虧損動態縮倉**：1-2筆100%、3-4筆70%、≥5筆50%
