# EMATrendMartingale v1.0 — 策略參數說明文件

## 策略概述

**策略名稱：** EMATrendMartingale_v1.0  
**策略類型：** EMA 五線共振 + 馬丁格爾加倉  
**適用品種：** XAUUSD（黃金）  
**時間框架：** M30（30 分鐘）  
**MagicNumber：** 20415  

---

## 核心交易邏輯

### 一、入市條件（五線共振順排）

EA 在 M30 圖表上監控五條 EMA：3、6、15、30、60。

**多頭入市（BUY）：**
- 條件：EMA3 > EMA6 > EMA15 > EMA30 > EMA60
- 要求：五條線完全發散，沒有任何兩條交叉或黏合（距離 ≥ MinEMADistancePips）
- 動作：開第一張 Buy 單（手數 = FirstLot）

**空頭入市（SELL）：**
- 條件：EMA60 > EMA30 > EMA15 > EMA6 > EMA3
- 要求：五條線完全發散
- 動作：開第一張 Sell 單（手數 = FirstLot）

### 二、馬丁加倉邏輯

當持倉方向逆行達到 AddOrderStep 點數時：
- 加倉手數 = 上一層手數 × MartinMultiplier
- 最多加倉 MaxMartinLevels 層
- 每次加倉更新 lastEntryPrice

### 三、出場條件

| 優先級 | 條件 | 說明 |
|--------|------|------|
| 1 | 回撤保護 | 淨值回撤 ≥ MaxDrawdownPercent（可選開關） |
| 2 | 趨勢破壞 | 任何相鄰 EMA 交叉即平倉（可選開關） |
| 3 | 整體止盈 | 所有訂單浮盈合計 ≥ 淨值 × TargetProfitPercent |

## 風險評估

### 風險等級：中高

**主要風險：**
1. **馬丁格爾風險**：連續加倉可能導致資金快速消耗，特別是在單邊行情中
2. **趨勢反轉風險**：EMA 五線共振信號有滯後性，可能在趨勢末端入場
3. **點差風險**：黃金在新聞事件時點差可能急劇擴大

**風險控制建議：**
1. 建議 MaxMartinLevels 不超過 5-8 層
2. 建議 AddOrderStep 設為 200-500 點（根據波動率調整）
3. 建議啟用 EnableDrawdownProtect 並設置 MaxDrawdownPercent 為 3-5%
4. 建議 FirstLot 不超過帳戶淨值的 0.5%
5. 避免在重大新聞發布前後交易

## 優化建議

1. **EMA 週期優化**：可嘗試 5/10/20/40/80 組合，適應不同波動環境
2. **加倉間距動態化**：根據 ATR 動態調整 AddOrderStep
3. **分層倍率遞減**：高層數使用較小倍率（如 1→4 層用 1.5x，5→10 層用 1.1x）
4. **時段過濾**：避開亞盤低波動時段，專注歐美盤交易
5. **多品種分散**：同時監控 XAUUSD + EURUSD + GBPUSD 降低單一品種風險
