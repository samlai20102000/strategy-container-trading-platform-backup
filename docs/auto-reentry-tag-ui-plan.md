## 策略卡片「自動重新入市」視覺標籤功能規劃與 UI 設計

### 1. 功能定義

此功能旨在策略列表的每張卡片上，直觀顯示該策略是否已啟用「自動重新入市」功能。其核心邏輯是從策略的配置中提取重新入市的狀態，並在前端以統一的視覺樣式呈現。

-   **數據來源**：標籤的啟用狀態將來自 `strategy.reentryEnabled` 字段。此字段已在後端 `server/routers.ts` 中處理，會根據不同策略的配置類型（如 KAMA 彩虹馬丁、V35、V50、V61 等）從其內部配置中提取正確的重新入市狀態。
-   **通用性**：標籤應適用於所有支持重新入市功能的策略，而不僅限於 KAMA 彩虹馬丁。
-   **狀態顯示**：標籤應清晰顯示「開啟」或「關閉」狀態。
-   **提示信息**：當用戶鼠標懸停在標籤上時，應顯示詳細的提示信息，解釋重新入市功能的含義。

### 2. UI 設計建議

-   **位置**：標籤應放置在策略卡片標題區域，緊鄰交易對符號（`s.symbol`）之後。這將確保其與其他策略相關的徽章（如交易所徽章）保持一致的視覺風格，且易於識別。
-   **樣式**：
    *   **開啟狀態**：使用鮮明的顏色組合，以突出其啟用狀態。建議使用綠色系或藍色系，例如：`bg-emerald-500/15 text-emerald-400 border-emerald-500/30`。這將給用戶一種「活躍」或「正常運行」的視覺反饋。
    *   **關閉狀態**：使用中性色組合，以表示其未啟用狀態。建議使用灰色系或鋅色系，例如：`bg-zinc-500/15 text-zinc-400 border-zinc-500/30`。這將給用戶一種「非活躍」或「已停止」的視覺反饋。
    *   **字體大小**：保持與其他徽章一致的字體大小，例如 `text-[10px]`，以維持整體視覺和諧。
    *   **邊框**：所有徽章都應有細微的邊框，以增加視覺層次感和區分度。
-   **內容**：標籤文字應簡潔明瞭，例如「自動重入：開啟」或「自動重入：關閉」。
-   **響應式設計**：確保在不同屏幕尺寸下，標籤能夠良好地顯示，不影響卡片佈局。`flex flex-wrap` 類應能確保在空間不足時自動換行。

### 3. 實作步驟

1.  **後端 `server/routers.ts` 修改**：
    *   確保 `strategiesRouter.list` 返回的每個策略物件都包含 `reentryEnabled` 字段。此步驟已完成，邏輯已根據不同策略類型從其配置中提取重新入市狀態。

2.  **前端 `client/src/pages/Strategies.tsx` 修改**：
    *   **定位渲染位置**：在策略卡片的渲染邏輯中，找到 `s.symbol` 徽章之後的代碼位置。
    *   **條件渲染**：根據 `s.reentryEnabled` 的布爾值，條件性地渲染一個 `<Badge>` 組件。
    *   **應用樣式**：根據 `s.reentryEnabled` 的狀態，動態應用上述 UI 設計建議中的 CSS 樣式。
    *   **添加提示**：為 `<Badge>` 組件添加 `title` 屬性，提供詳細的懸停提示信息，例如：「此策略已啟用自動重新入市功能，平倉後將根據條件自動重新開倉。」或「此策略未啟用自動重新入市功能。」
    *   **移除 KRM 專屬邏輯**：移除原先 KRM 策略專屬的重新入市徽章邏輯，改為通用處理。

### 4. 考慮因素

-   **同一個方向入市下的買賣、同一個方向入市下第幾次買賣**：這些更細粒度的重新入市邏輯屬於策略內部配置的細節，`reentryEnabled` 標籤僅表示該功能是否「總體啟用」。如果需要顯示這些細節，則可能需要將其作為單獨的徽章或在策略詳情頁中展示，以避免卡片信息過於擁擠。目前規劃中，此標籤僅顯示總體啟用狀態。
-   **性能影響**：由於 `reentryEnabled` 字段已在後端處理並隨策略列表一同返回，前端僅需進行條件渲染，對性能影響極小。
