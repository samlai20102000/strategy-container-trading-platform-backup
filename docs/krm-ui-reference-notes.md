## 精讀核對結果

圖一是深色介面，欄位標籤為「時間框架」，下方下拉選擇器目前顯示「30 分鐘」。改版應保留既有視覺語言、清楚的下拉狀態與 30 分鐘預設，但不得再把 30 分鐘視為固定值。

圖二左側標題為「SECTOR 03 固定間距指數馬丁」，主要欄位包含「最大層數（含底倉）」；卡片預覽以 L1、L2 等層級列出 USDT 數量及指數倍數。這證實現有 UI 是單一全域乘數的固定公式預覽，不符合使用者要求的可編輯分段規則。

圖二中段另有全域「層級倍率」欄位，範例值為 2；右側為「相鄰層實際成交間距」，範例值為 2，並提示 LONG 向下、SHORT 向上。層級預覽顯示 L3＝400 USDT（`2^2 × 底倉`）、L4＝800 USDT（`2^3 × 底倉`）。新設計必須以每個分段的乘數與可選分段間距取代單一全域公式，同時保留方向語義及累積曝險預覽。

圖二末層預覽為 L5＝1,600 USDT（`2^4 × 底倉`），進一步確認舊介面完全依全域指數公式生成。

圖三目標區塊標題為「馬丁加倉與分層參數」。啟用分層後，`Martin_Multiplier` 顯示已鎖定並提示改由表格設定各層乘數；表格標示「階梯式馬丁分層（乘數＋間距）」且說明可任意設定各層間距。左側欄位為「起始／結束／乘數」，預設三列 1–4＝1.5、5–9＝1.1、10–11＝1，並有「新增分層」按鈕。這些互動是 Kama 彩虹馬丁新版 UI 的核心參考。

圖三中段保留 `Martin_Step_Pct（全局加倉間距 %）` 作為回退值；當某分層未設定專屬間距時，該分層顯示「全局」並使用全域間距。每列另有「累積」倍率預覽與刪除按鈕。右側 `Max_Layers` 顯示鎖定及「自動計算」，數值取分層表格最後一列的結束層（範例為 11）。因此新版資料契約需明確區分「分層專屬間距」與 `null`／未填時的全域回退，而不能把 0 當成空值。

## 使用者已確認的預設分層

| 層級範圍 | 乘數 |
| --- | ---: |
| L1–L4 | 1.5 |
| L5–L9 | 1.1 |

使用者明確要求可以自行新增層級；因此介面及後端必須支援新增、刪除、編輯與共同驗證，而非只顯示固定三列。

## 全系統同步範圍

回測中心、專用回測引擎、實盤策略交易、參數快照庫、從快照套用／複製為新策略、策略註冊 schema，以及 S1／M2／H3 三模式部署的配置解析、保存與執行都必須保留同一份 `timeframe` 與分層馬丁資料，避免 UI 與底層漂移。
