## 1. 策略概述

KAMA 3K 動態馬丁策略是一套結合 **Kaufman 自適應移動平均線（KAMA）趨勢過濾** 與 **3K 形態突破入場** 的馬丁格爾加倉系統。策略以「固定金本位」模式運作，首單以固定 USDT 金額入場，後續加倉按階梯式乘數遞增，並搭配移動止盈（Trailing Take-Profit）和多層硬止損機制進行風控。

策略的核心設計理念是：利用 KAMA 雙線交叉確認中期趨勢方向，再以連續同色 K 線突破形態（3K Pattern）作為精確入場觸發，配合馬丁格爾逆勢加倉攤平成本，最終在趨勢回歸時以移動止盈鎖定利潤。

## 2. 核心指標：KAMA（Kaufman Adaptive Moving Average）

### 2.1 計算公式

KAMA 是一種自適應均線，其平滑係數根據市場「效率比」（Efficiency Ratio）動態調整。在趨勢明確時 KAMA 反應迅速，在震盪時則趨於平坦，有效過濾雜訊。

> **效率比（ER）**：衡量價格方向性移動與總波動的比值  
> **平滑常數（SC）**：根據 ER 在快慢常數之間插值，再取平方以增強自適應效果

完整公式如下：

```
ER = |Close[i] - Close[i - Length]| / Σ|Close[j] - Close[j-1]|  (j = i-Length+1 到 i)

fastSC = 2 / (fastest + 1)
slowSC = 2 / (slowest + 1)
SC = (ER × (fastSC - slowSC) + slowSC)²

KAMA[i] = KAMA[i-1] + SC × (Close[i] - KAMA[i-1])
```

初始值取 `Close[Length]` 作為 KAMA 起點（與 TradingView Pine Script `ta.kama` 慣例一致）。

### 2.2 雙線配置

本策略使用 **快線** 和 **慢線** 兩條 KAMA，透過其相對位置判斷趨勢方向：

| 參數 | 快線（Fast） | 慢線（Slow） | 說明 |
|------|:---:|:---:|------|
| **Length** | 50 | 50 | 計算週期（回望長度） |
| **Fastest** | 10 | 10 | 最快平滑常數（趨勢明確時的反應速度） |
| **Slowest** | 2 | 6 | 最慢平滑常數（震盪時的平滑程度） |

**趨勢判定規則**：
- **多頭趨勢**：KAMA 快線 > KAMA 慢線
- **空頭趨勢**：KAMA 快線 < KAMA 慢線

快線的 `slowest=2` 使其在趨勢中反應極快（接近價格本身），而慢線的 `slowest=6` 則更為平滑，兩者的差異形成了趨勢方向的判斷基礎。

## 3. 入市條件（Entry）

### 3.1 3K 形態突破

入市信號基於「3K 形態」——連續三根 K 線形成的突破結構：

**做多條件（Long Entry）**：
1. K1（前第二根）為陽線：`Close[K1] > Open[K1]`
2. K2（前第一根）為陽線：`Close[K2] > Open[K2]`
3. K3（當前根）收盤突破前兩根最高價：`Close[K3] >= max(High[K1], High[K2])`
4. **KAMA 方向鎖**：KAMA 快線 > KAMA 慢線（確認多頭趨勢）

**做空條件（Short Entry）**：
1. K1（前第二根）為陰線：`Close[K1] < Open[K1]`
2. K2（前第一根）為陰線：`Close[K2] < Open[K2]`
3. K3（當前根）收盤跌破前兩根最低價：`Close[K3] <= min(Low[K1], Low[K2])`
4. **KAMA 方向鎖**：KAMA 快線 < KAMA 慢線（確認空頭趨勢）

### 3.2 KAMA 方向鎖（Direction Lock）

KAMA 方向鎖是一道額外的信號過濾層，確保只在趨勢方向上開倉：

- 做多信號：若當前價格 < KAMA 值，則拒絕（價格在 KAMA 下方，不符合多頭條件）
- 做空信號：若當前價格 > KAMA 值，則拒絕（價格在 KAMA 上方，不符合空頭條件）

### 3.3 信號驗證五層檢查（V3.5）

在信號進入執行管線前，系統會進行五層驗證：

| 檢查層 | 內容 | 拒絕條件 |
|:---:|------|------|
| 1 | 冷卻期檢查 | 若處於冷卻期（`cooldownUntil > 當前時間`），拒絕信號 |
| 2 | KAMA 方向鎖 | 做多時價格 < KAMA 值，或做空時價格 > KAMA 值 |
| 3 | 反向持倉檢查 | 持有空倉時拒絕做多信號，持有多倉時拒絕做空信號 |
| 4 | CLOSE 信號 | CLOSE 信號始終有效，跳過所有檢查 |
| 5 | Bar-Lock | 同一根 K 線內不重複開倉（防止重複觸發） |

### 3.4 首單倉位計算

策略採用 **固定金本位** 模式，首單以固定 USDT 金額入場：

```
首單數量（BTC）= Base_Lot_Size（USDT）/ 當前價格
```

例如：`Base_Lot_Size = 30 USDT`，當前 BTC 價格 = 64,000 USDT  
→ 首單數量 = 30 / 64000 = 0.00046875 BTC

系統同時支持 `Position_Mode` 切換：
- **usdt 模式**：以 USDT 金額計算（如上）
- **quantity 模式**：直接指定 BTC 數量

## 4. 馬丁格爾加倉邏輯（Martingale Add-Layer）

### 4.1 加倉觸發條件

當持倉後價格逆向移動，偏離持倉均價達到設定的間距百分比時，觸發加倉：

```
偏離度 = (均價 - 當前價格) / 均價 × 100%    （做多）
偏離度 = (當前價格 - 均價) / 均價 × 100%    （做空）

觸發條件：偏離度 >= Martin_Step_Pct（默認 2.0%）
```

額外限制：
- 當前層數 < Max_Layers（默認 11 層）
- 加倉後剩餘資金 >= 加倉成本

### 4.2 階梯式分層乘數

本策略使用 **階梯式分層乘數**（而非固定乘數），不同層數區間使用不同的加倉倍率：

| 層數區間 | 乘數 | 說明 |
|:---:|:---:|------|
| 第 1–4 層 | 1.5× | 前期積極加倉，快速攤平成本 |
| 第 5–9 層 | 1.1× | 中期保守加倉，控制總倉位 |
| 第 10–11 層 | 1.0× | 後期不再放大，防止倉位失控 |

### 4.3 加倉倉位計算

每層加倉的 USDT 金額按累乘計算：

```
第 N 層金額 = 首單金額 × 乘數[1] × 乘數[2] × ... × 乘數[N]
第 N 層數量（BTC）= 第 N 層金額 / 當前價格
```

同時設有 **4.5× 上限**（Cap）：任何單層金額不得超過首單金額的 4.5 倍，防止單層過大。

### 4.4 加倉後狀態更新

每次加倉成功後：
- 更新持倉均價：`新均價 = 總成本 / 總持倉量`
- 重置移動止盈追蹤（因均價已變動，需重新計算盈利百分比）
- 更新總持倉量和總成本

### 4.5 動態間距（V3.6 擴展）

分層規則支持 `stepPct` 自定義間距，不同層數可使用不同的加倉間距：

```json
[
  { "start": 1, "end": 4, "multiplier": 1.5, "stepPct": 1.5 },
  { "start": 5, "end": 9, "multiplier": 1.1, "stepPct": 2.5 },
  { "start": 10, "end": 11, "multiplier": 1.0, "stepPct": 3.0 }
]
```

若分層未指定 `stepPct`，則回退使用全局 `Martin_Step_Pct`。

## 5. 出市條件（Exit）

### 5.1 出市優先級

實盤監控每 20 秒檢查一次，按以下優先級順序執行（命中即停止）：

| 優先級 | 機制 | 觸發條件 | 後果 |
|:---:|------|------|------|
| 1 | **硬止損** | 總浮虧 ≥ Initial_Capital × Max_Loss_Pct% | 全平 + 暫停策略 + 冷卻 |
| 2 | **極限止損** | 條件 A 或 B（見下文） | 全平 + 暫停策略 + 冷卻 |
| 3 | **移動止盈** | 盈利激活後從最優價回撤 ≥ Callback_Pct% | 全平 + 分流判斷 |
| 4 | **馬丁加倉** | 偏離度 ≥ Martin_Step_Pct% | 加倉（不平倉） |

### 5.2 硬止損（Hard Stop Loss）

硬止損基於 **初始資金本金** 計算，而非當前倉位成本：

```
總浮虧 = (均價 - 當前價格) × 總持倉量    （做多）
總浮虧 = (當前價格 - 均價) × 總持倉量    （做空）

觸發條件：總浮虧 ≥ Initial_Capital × Max_Loss_Pct / 100
```

默認值：`Max_Loss_Pct = 5%`，`Initial_Capital = 10,000 USDT`  
→ 硬止損金額 = 500 USDT

觸發後：
1. 市價全平所有持倉
2. 暫停策略（需人工檢查後手動恢復）
3. 進入冷卻期（K_Line_Period × 2 分鐘）
4. 發送 Telegram 警報通知

### 5.3 極限止損（Limit Stop）

極限止損是硬止損之外的後備防線，防止極端行情下的爆倉風險：

**條件 A — 浮虧保護**：
```
持倉盈虧百分比 <= -Max_Drawdown_Pct（默認 -10%）
```

**條件 B — 最後層偏離保護**：
```
已達最大層數 AND 價格繼續偏離最後一層 >= Max_Deviation_Pct（默認 3%）
```

任一條件成立即觸發全平。

### 5.4 移動止盈（Trailing Take-Profit）

移動止盈分為三個階段：

**階段 1 — 激活**：
```
盈利百分比 = (當前價格 - 均價) / 均價 × 100%    （做多）
激活條件：盈利百分比 >= Target_TP_Pct（默認 1.0%）
```

**階段 2 — 追蹤最優價**：
- 做多：記錄最高價（`highestPrice`），價格每創新高即更新
- 做空：記錄最低價，價格每創新低即更新

**階段 3 — 回撤平倉**：
```
回撤百分比 = (最優價 - 當前價格) / 最優價 × 100%    （做多）
平倉條件：回撤百分比 >= Callback_Pct（默認 0.1%）
```

### 5.5 KAMA 反轉割肉（已移除）

> **V3.7 重要變更**：KAMA 反轉主動割肉機制（O2）已完全移除。原因是 KAMA 在馬丁持倉時頻繁出現騙線，導致大量盈利單被誤割。現改用純硬止損 `Max_Loss_Pct` 替代。

## 6. 平倉後分流機制（O3 Close Split）

平倉後系統根據馬丁深度和退出原因決定後續行為：

### 6.1 分流 A — 順勢重入（Trend Reentry）

**觸發條件**（三者同時滿足）：
1. 馬丁層數 = 0（僅首單，無加倉歷史）
2. 退出原因為止盈相關（`trailing_stop` / `take_profit`）
3. 當前 KAMA 方向與入場時一致（趨勢未變）

**行為**：立即市價重入首單，開始新一輪交易。不進入冷卻期。

### 6.2 分流 B — 強制冷卻（Cooldown）

**觸發條件**：
- 馬丁層數 ≥ 1（有加倉歷史）

**行為**：
- 進入冷卻期：`K_Line_Period × 2` 分鐘
- 冷卻期內拒絕所有新入場信號
- 等待冷卻結束後由新的 3K 形態觸發入場

### 6.3 分流 C — 風控性平倉

**觸發條件**：
- 退出原因為硬止損、極限止損、絕對金額限損

**行為**：
- 強制冷卻（即使無馬丁也冷卻）
- 暫停策略（硬止損觸發時）
- 需人工確認後手動恢復

## 9. OKX 合約適配

### 9.1 下單單位轉換

OKX 永續合約的 `sz` 參數單位為「張」（contracts），而非 BTC。系統內部以 BTC 計算，下單時進行轉換：

```
合約張數 = BTC 數量 / ctVal
```

其中 BTC-USDT-SWAP 的 `ctVal = 0.01 BTC/張`，`lotSz = 1 張`（最小步長），`minSz = 0.01 張`。

例如：首單 0.000469 BTC → 0.000469 / 0.01 = 0.0469 張 → 取整為 0 張（不足 1 張）

因此實際運行時，`Base_Lot_Size` 需設定足夠大的金額以確保首單至少 1 張合約（≈ 640 USDT @ BTC 64,000）。在 USDT 模式下，系統會自動將 USDT 金額轉換為 BTC 再轉換為張數。

### 9.2 持倉模式

系統支持 OKX 雙向持倉模式（`posSide`），下單時自動推斷：
- 買入開多：`posSide = "long"`
- 賣出開空：`posSide = "short"`

## 10. 風險特徵與注意事項

### 10.1 最大風險暴露

以默認參數計算，11 層全部加滿時的最大倉位：
- 累計投入：約 1,152 USDT
- 佔初始資金比例：11.5%
- 硬止損觸發金額：500 USDT（本金的 5%）

### 10.2 策略優勢

1. **自適應趨勢過濾**：KAMA 雙線在震盪市中自動收窄，減少假信號
2. **精確入場**：3K 形態要求連續同色 K 線 + 突破，過濾了大部分隨機波動
3. **階梯式加倉**：前期積極攤平，後期保守控制，避免倉位指數級膨脹
4. **移動止盈**：鎖定利潤的同時允許趨勢延續，不會過早離場
5. **順勢重入**：首單止盈後若趨勢未變，立即重入捕捉延續行情

### 10.3 風險警示

1. **單邊極端行情**：若價格持續單邊移動超過 11 層間距（約 22%），馬丁將無法繼續攤平
2. **硬止損觸發**：硬止損觸發意味著本輪策略失敗，需人工介入判斷市場環境
3. **流動性風險**：極端行情下市價單可能產生較大滑點
4. **資金效率**：馬丁策略需要預留大量資金應對加倉，實際資金利用率較低
