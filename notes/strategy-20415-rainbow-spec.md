# 20415 七彩虹馬丁策略規格與相容決策

## 任務邊界

本次以使用者文件 `pasted_file_RlrtGe_20415七彩虹馬丁策略執行命令.txt` 為優先規格，保留穩定身份 `strategy_20415`，將既有 **EMA 均線回歸馬丁格爾（優化版）** 的名稱、參數、決策核心、回測與專用 UI 原位換成 **20415七彩虹馬丁策略**。其他 KAMA、V3.5、V5.0、V6.1、V7.0 與自訂策略的鍵、配置及決策語義不得改動。

| 項目 | 七彩虹規格 | 平台裁決 |
|---|---|---|
| 空倉入場 | M30 已收盤 K 棒，七線斜率全部同向且前後排名識別序列完全一致 | 排名比較線 ID，不比較排序後數值本身；同值視為不確定並拒絕入場 |
| 持倉管理 | 每分鐘盲人模式 | 持倉後七線不干預，只讀真實現價、加權成交均價、層級與帳戶資料 |
| 底倉 | 第一層為 `baseLot` | `currentLayer = 1` 只在首單真實成交後寫入 |
| 馬丁 | 動態連續範圍，可增刪、可停用、全局或自訂間距 | 不設硬編碼層數上限；加倉量為 `baseLot × 當前範圍 multiplier` |
| 止盈 | 平均成本名義價格盈利預設 0.2% | 多空對稱全平，不乘槓桿 |
| 鐵幕一 | 最大持倉預設 48 小時 | 達門檻全平 |
| 鐵幕二 | 保證金使用率預設 70% | 使用真實交易所帳戶資料；缺少資料時封鎖加倉 |
| 鐵幕三 | 最終有效層後帳戶虧損預設 5% | 只在已達最後有效層且真實帳戶損益達門檻時全平 |
| 重入 | 平倉後重新判斷七線 | 結構仍成立且冷卻完成可重入；結構破壞則返回空倉掃描 |

## 原位取代與資料相容

策略 key 與既有 JSON 容器維持 `strategy_20415` 及 `martinState.__v2_0Config`，新配置加入固定版本 `rainbow20415.v1`。建立、編輯、回測、快照與部署均先經相同正規化及嚴格校驗。舊 EMA 配置只遷移語義安全的 `Base_Lot_Size` 與 `Initial_Capital`；EMA 三線、ATR pipstep、舊 points 止盈、硬止損金額與固定最大層數均不得誤解為七彩虹欄位。

2026-07-25 的唯讀資料盤點顯示，當時生產資料庫內 `strategy_20415` 策略實例與參數快照均為零，因此發布時沒有舊 20415 持倉需要接管。相容層仍保留，供下載檔、跨環境快照或日後匯入使用。

## 執行與資料誠信

既有 Heartbeat 是唯一週期來源。空倉時只使用最新已收盤 M30 K 棒，持倉時每分鐘管理；禁止新增 `setInterval`、cron 或自管常駐程序。首單、加倉與平倉都只在交易所回報成功後更新持久化狀態，失敗時不得前推層級或均價。不得使用 `Math.random()`、模擬盈虧、假成交或假保證金。

## 驗收矩陣

確定性測試必須涵蓋多空入場、排名交叉拒絕、同值拒絕、盲人模式、停用層跳過、加權均價、0.2% 止盈、48 小時／70%／5% 三道風控、重入、M30 去重、舊配置升級、快照往返、註冊、執行與回測。最終執行 TypeScript、完整 Vitest、生產建置及桌面／390px 視覺驗收；驗收期間不建立策略、不提交回測、不啟用自動交易且不下單。
